=== "Agents"

    ```python
    from workers import Request, Response, WorkerEntrypoint
    from agents import Agent, callable, route_agent_request


    class Counter(Agent):
        initial_state = {"count": 0}

        @callable  # clients call this over a WebSocket
        async def increment(self, by: int = 1) -> int:
            self.set_state({"count": self.state["count"] + by})  # saved, sent to every client
            return self.state["count"]


    class Default(WorkerEntrypoint):
        async def fetch(self, request: Request) -> Response:
            # /agents/counter/<name> reaches the counter called <name>
            return await route_agent_request(request, self.env) or Response("Not found", status=404)
    ```

=== "Containers"

    ```python
    from workers import Request, Response, WorkerEntrypoint
    from containers import Container, get_container


    class Transcoder(Container):
        default_port = 8080
        sleep_after = "5m"
        enable_internet = False


    class Default(WorkerEntrypoint):
        async def fetch(self, request: Request) -> Response:
            # One container per video, started on the first request
            video_id = request.url.rsplit("/", 1)[-1]
            container = get_container(self.env.TRANSCODER, video_id)
            return await container.fetch(request)
    ```

=== "Sandboxes"

    ```python
    from sandboxes import Files
    from workers import DurableObject, Request, Response, WorkerEntrypoint


    class Sandbox(DurableObject):
        async def save(self, text: str) -> str:
            if not self.ctx.container.running:
                self.ctx.container.start()

            files = Files(self.ctx.container)
            await files.mkdir("/workspace", recursive=True)
            await files.write_file("/workspace/notes.txt", text)  # still there on the next request
            entries = await files.read_directory("/workspace")
            return ", ".join(entry.name for entry in entries)


    class Default(WorkerEntrypoint):
        async def fetch(self, request: Request) -> Response:
            # One sandbox per user, with its own container and files
            user_id = request.url.rsplit("/", 1)[-1]
            sandbox = self.env.SANDBOX.getByName(user_id)
            return Response(await sandbox.save(await request.text()))
    ```

=== "Workers"

    ```python
    from env import Env  # generated by wynd from wrangler.jsonc
    from workers import DurableObject, Request, Response, WorkerEntrypoint


    class Counter(DurableObject[Env]):
        async def increment(self, by: int) -> int:
            count = (await self.ctx.storage.get("count") or 0) + by
            await self.ctx.storage.put("count", count)
            return count


    class Default(WorkerEntrypoint[Env]):
        async def fetch(self, request: Request) -> Response:
            # self.env.COUNTER is typed, so a misspelled method fails the type check
            count = await self.env.COUNTER.get_by_name("global").increment(1)
            return Response.json({"count": count})
    ```

## What Crosswind is

[Python Workers](https://developers.cloudflare.com/workers/languages/python/)
run Python on Cloudflare's network. Several Cloudflare products ship their
developer kits only for TypeScript, so using them from Python means calling
JavaScript objects through Pyodide's foreign function interface.

Each Crosswind package ports one of those kits to Python. You subclass a Python
class, override `async` methods and call typed functions, and the package
makes the JavaScript calls.

## How the packages work

- **Python classes.** You subclass a class and override `async` methods.
  Bindings and state have type hints, so a type checker catches a misspelled
  method before you deploy.
- **TypeScript behaviour.** Each package keeps the defaults, timeouts and wire
  protocols of the TypeScript SDK it ports. The Cloudflare docs for that
  product still describe what your code does, and TypeScript clients such as
  the `useAgent` React hook connect to a Python Worker unchanged.
- **Web frameworks.** `crosswind-workers` serves ASGI apps such as FastAPI and
  Starlette, and WSGI apps such as Flask. See
  [Serve FastAPI or Flask](workers/web-frameworks.md).

## Status

Every package is alpha and pre-1.0. A minor release can break your code, so
pin exact versions:

```sh
uv add "crosswind-workers==<version>"
```

Each SDK's overview lists the features it doesn't port yet. Crosswind is an
independent community project. It isn't affiliated with or endorsed by
Cloudflare.
