    What is Crosswind?

    Python Workers run Python on Cloudflare's global network, but getting beyond "hello world" often means dropping down to JavaScript bindings, hand-rolling glue code, or hitting the edges of what the runtime supports.

    Crosswind closes that gap. Each SDK gives Python Workers first-class, Pythonic access to a part of the Cloudflare platform and pushes them into workloads they couldn't handle on their own. You write idiomatic, typed, async Python; Crosswind handles the plumbing.

    Why Crosswind?

    Pythonic by design

    Typed, async-first APIs that read like Python, not JavaScript translated line by line.

    Past the runtime's limits

    Move heavier, longer-running and more specialised work out of the isolate without leaving Python.

    More of the platform

    Reach more Cloudflare products from Python, with one consistent developer experience across every SDK.

    Small and focused

    Separate packages per product. Install only what you need and keep your Worker lean.
