containers-py
</h1>
<p align="center">
<sup>
Cloudflare Containers for Python Workers
</sup>
</p>

Use `containers-py` to start Cloudflare Containers and route requests to them from a Python Worker. Read the [Containers docs](https://crosswind.viswa.space/containers/overview/) for setup and examples.

> [!note]
> This is an unofficial SDK, not affiliated with Cloudflare. I wrote a first port during my internship at Cloudflare, and this package is a rewrite of it. I used AI tools to write it and review every change.
>
> This project is part of [Crosswind](https://crosswind.viswa.space).
